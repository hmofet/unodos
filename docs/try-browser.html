Try it in your browser

The quickest look at UnoDOS costs nothing and installs nothing: open it in a browser tab. It is the real release image running on an emulated PC compiled to WebAssembly, not a video and not a mock-up, and the desktop arrives in a few seconds on a current machine.

Boot UnoDOS in your browser

What you are looking at

  • The screen is 1600x900, one desktop pixel to one screen pixel. The Size control above it picks the zoom; whole multiples stay pixel-sharp.
  • The disk is a RAM disk. You can write to it, and nothing survives a reload - which makes it a good place to try the things this manual warns about.
  • The machine has a working network card and takes an address, but that network ends inside the tab. See Networking.
  • Duum is on the disk with its game data, but an emulated PC runs it at well under one frame a second. It is worth seeing rather than playing; the browser port of Duum plays properly.
Leave the tab in frontA tab in the background is throttled by the browser, which stops the emulated machine rather than just the picture. The page says paused when that happens; bring the tab back to the front and it carries on.

What the browser cannot show you

Every instruction is being emulated, so the machine is far slower than the same OS on real hardware, and anything that leans on the CPU shows it. Sound, the hardware drivers and the true speed of the desktop are properties of a real PC. When you want those, Getting started puts UnoDOS on a USB stick in a few minutes.
