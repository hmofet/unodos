**Boot contract (per EMILE first.S + IM:Files p2-57)**: sector 0-1 = 1024-byte boot blocks: $4C4B 'LK', bra.w entry (the 4-byte bbEntry), version $4418 (bit6 of high byte = execute boot code; old-format header ends at bbSysHeapSize). At entry: supervisor mode, A-traps live, .Sony open — PBReadSync $A002 with ioVRefNum=1, ioRefNum=-5, fsFromStart, ioPosOffset=1024 reads raw bytes regardless of FS. Boot code must be PIC. Kernel org $20000, stack $78000, vasm -Fbin; mkdisk.py patches 'KSIZ' placeholder with kernel size; 800K image = 819200 B.

**Hardware truth (verified vs MAME mac128.cpp + TMK m0110)**: VIA1 base $EFE1FE stride $200/reg (ORB+0 DDRB+$400 SR+$1400 ACR+$1600 PCR+$1800 IFR+$1A00 IER+$1C00); IFR bit1=CA1 vblank 60.15Hz, bit2=SR; PB3=button(low=down) PB4=X2 PB5=Y2; don't touch port A (PA4=ROM overlay). SCC reads $9FFFF8(chB)/$9FFFFA(chA), writes $BFFFF9/$BFFFFB; mouse X1=DCD-A, Y1=DCD-B (RR0 bit3); WR15=$08+WR1=$01+WR9=$08 enables DCD ints; WR0=$10 resets ext/status latches. Keyboard M0110: VIA SR shift-out-ext-clk (ACR mode 111) to send Instant $14, switch to shift-in (011) for response; wire byte=(scan<<1)|1, bit7=release, $7B=null, $79=keypad/arrow prefix (arrows scan|$40: up $4D dn $48 lt $46 rt $42 → translate to canonical UnoDOS raws $4C/$4D/$4F/$4E). No ESC key: '`' (scan $32) maps to ESC.

**ROM-free harness (macplus/harness.py, pip unicorn)**: Unicorn UC_CPU_M68K_M68000 quirks discovered by probing — (1) A-line opcode → UC_HOOK_INTR intno=10 with PC still AT the opcode, NO auto-vectoring/stack push: emulate trap in Python, advance PC manually; (2) RTE → intno=0x100 (QEMU EXCP_RTE), frame pop is YOUR job → inject interrupts by pushing 6-byte SR.w+PC.l frames at slice boundaries and pop the same format on 0x100 — fully symmetric, kernel ISRs (movem/rte) just work; (3) reg_write SR=0x2700 sticks (supervisor + privileged ops fine); (4) device pages = mem_map + UC_HOOK_MEM_READ writes the value into memory before the read completes. Run slices (emu_start count=2500), tick CA1 every 6 slices, closed-loop mouse via the kernel's 'UDM1' header at KERNBASE+4 (points to vars; mouse_x at vars+24). tests/m1.script = M1 regression.

**Trap (3rd in the flags family)**: `or.b d3,d0` + `beq` dropped all arrow key events — or.b sets flags from the LOW BYTE only; the raw code lived in the high byte (ascii=0). tst.w before branching on composed words. Same family as find_window_at tst-before-rts.
